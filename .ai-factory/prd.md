# choresplit

## Platform
앱인토스 (Vite + React + TDS)

## One-liner
동거인과 집안일 기여도를 매일 기록해 공정하게 정산해주는 가사분담 트래커

## Problem
룸메이트·동거 커플·신혼부부 사이 가사노동 분담 불균형으로 갈등이 발생하지만 이를 객관적으로 기록·정산할 도구가 없다

## Target Users
1-2인 동거 가구, 신혼부부, 룸메이트로 함께 사는 2030대

## Core Features
1. 집안일 항목별 일일 체크인 로그(설거지·청소·빨래 등)
2. 동거인 초대 후 각자 기여도 실시간 반영
3. 주간 공정성 점수+상세 리포트(리워드 광고 시청 후 열람)
4. 미이행 항목 소액 벌금 설정 및 정산 제안
5. 스트릭·랭킹으로 게임화된 습관 형성
6. 매일 체크인 리마인더

## Monetization
- Model: ads
- Estimated MRR: 약 58만원/월 (배너+리워드 광고 기준)
- Reasoning: 일일 체크인 습관 형성 구조로 DAU 유지에 유리하고, 주간 리포트를 리워드 광고 뒤에 배치해 반복 전환을 기대할 수 있음
